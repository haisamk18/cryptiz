## ✨ Overview

Cryptiz is an AI-powered Web3 security platform designed to help users understand and monitor wallet risks in real time.

Instead of manually checking token approvals, suspicious contracts, and risky interactions, Cryptiz scans wallet activity and explains potential threats in simple language.

The platform focuses on making crypto wallet security understandable for everyday users.

---

## 🚀 Features

### 🔐 Wallet Security Scan

- Connect wallet using MetaMask
- Real-time wallet analysis
- Fetch wallet balances
- Generate wallet risk score
- Scan suspicious interactions

---

### 🛡️ Approval Scanner

- Detect active token approvals
- Identify risky smart contracts
- Detect unlimited token permissions
- Approval risk indicators
- Revoke approval actions

Example:

> "You granted unlimited USDT approval to a suspicious contract."

---

### 🚨 Scam Detection

Detect:

- Honeypot tokens
- Dusting attacks
- Fake airdrops
- Impersonation tokens
- Suspicious transaction behavior

---

### 🤖 AI Security Assistant

AI-generated explanations for wallet activity.

Examples:

> "Can this approval drain my wallet?"

> "Why is this wallet considered risky?"

> "Is this token safe?"

Features:

- Human-readable explanations
- Security recommendations
- Wallet behavior analysis

## ⚙️ Run Locally

Clone repository:

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/cryptiz.git
```

Go into project:

```bash
cd cryptiz
```

Install frontend dependencies:

```bash
cd client
npm install
```

Install backend dependencies:

```bash
cd ../server
npm install
```

Create environment variables:

```env
ALCHEMY_URL=YOUR_ALCHEMY_KEY
PORT=5000
```

Run backend:

```bash
npm run dev
```

Run frontend:

```bash
cd ../client
npm run dev
```
